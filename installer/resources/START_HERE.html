FEC-RTTY - M0NXD

A 24-hour digital-mode experiment: a plaintext text modem with FEC, a scalable GUI and real-audio transmit/decode testing. Subsequent development and limitations are recorded in the included documentation. This is an experimental bench build, not a certified radio product.

Everything needed to run the application is installed together. No developer SDK or separate runtime download is needed. CAT/PTT remains disabled; nothing here enables radio keying.

Start the application

Open FEC-RTTY - M0NXD from the Windows Start menu, or launch gui\fectty-gui.exe in this installation. Keep its DLL and plugin folders intact. The same executable can run twice.

Two-window bench test

  1. Launch two copies and choose the same audio backend in both.
  2. With VB-CABLE already installed, select CABLE Output for RX and CABLE Input for TX.
  3. Keep NullRig / bench mode and start both sessions.
  4. Use linked 1500 Hz offsets initially. With split tuning, sender TX must match receiver RX.
  5. Send a short message from one window, check exact decoded text in the other, then test the reverse direction. Send one at a time; the shared cable can carry your own audio too.

The output-volume slider reduces audio amplitude; it is not a measurement of safe radio drive. Waterfall sensitivity changes brightness only. Stop cancels TX, and cancelled drafts are preserved.

Uninstall or repair

Use Windows Settings → Apps → Installed apps (or Apps & features), find FEC-RTTY - M0NXD and select Uninstall. The same entry appears in Control Panel → Programs and Features. Close installed copies first. Rerun setup to repair this installed version.

Uninstall removes application-owned files and shortcuts. It preserves your settings at %LOCALAPPDATA%\FEC-RTTY\FEC-RTTY\fectty.ini, user-created files and shared audio drivers.

Optional VB-CABLE

Normal sound-card operation does not need a virtual cable. For two-application bench tests, download VB-CABLE separately from its vendor and follow its instructions, license and administrator/restart workflow. FEC-RTTY does not bundle, install, upgrade or remove shared drivers.
