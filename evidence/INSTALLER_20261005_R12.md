## Optional driver, safety and remaining gates

The application runtime prerequisites are embedded. VB-CABLE is **not** an
application requirement and is not automatically installed/uninstalled.
Its original vendor ZIP is supplied unchanged as a separate manual-install
extra, with origin/donationware notices. Existing drivers were left alone.
Vendor setup requires admin/restart; it was not executed in these tests.
Website/package integration terms need reconciliation before public bundling.
Qt/GNU/PortAudio/Inno notices and Qt inventories/source references are included,
not a claim of completed public licensing/corresponding-source review.

Optional external OmniRig COM providers, a radio-connected rigctld service,
and hardware drivers are not bundled app runtimes. NullRig bench operation
does not require them, and this installer does not enable radio keying.

The normal Windows registry/uninstaller route was exercised; Windows Settings
and Control Panel were **not** driven by UI automation. No clean VM, every
Windows version/scale/account, real radio/driver install/restart, ARM64/x86,
new-version migration, code signing or SmartScreen reputation certification.
Original modem stop/backlog, independent-clock/path and RF limits remain.
No encryption, CAT/PTT keying, new profile or remote push was introduced.
