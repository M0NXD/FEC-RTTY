# FEC-RTTY documentation

New to the project? Read the [main README](../README.md), then choose:

- [Build from source](BUILDING.md): dependencies, core tools and GUI deployment.
- [Test the modem](TESTING.md): automated tests and virtual-cable setup.
- [Use the GUI](GUI_PACKAGE.md): audio, output level, waterfall and offsets.
- [Understand the implementation](PROJECT_GUIDE.md): architecture and limitations.
- [Implement the protocol](PROTOCOL.md): framing, FEC, tones and receiver behavior.

For developers, see [GUI design](GUI_DESIGN.md), [Roadmap](DEVELOPMENT_PLAN.md),
[Installer design](INSTALLER.md) and [Publishing](PUBLISHING.md).
Get Windows downloads from the [latest release](https://github.com/M0NXD/FEC-RTTY/releases/latest).

`TEST_RESULTS_*` and `DEVELOPMENT_PLAN_SOURCE.txt` are historical records.
They are not current setup instructions. More dated observations are in
[the evidence index](../evidence/README.md). Only the current source tree is
published. Use [PROJECT_INDEX.md](../PROJECT_INDEX.md)
for navigation across current and historical material.
